# Archive Integrity Verification

## Overview
Verification checks the internal CRC-32 or SHA-256 checksums of every item inside an archive to detect corrupted downloads or storage bit-rot.

## How to Verify
Right-click an archive file and select **Test / Verify Archive Integrity**. The Operation Center tests each archive block and reports any corrupted files.
