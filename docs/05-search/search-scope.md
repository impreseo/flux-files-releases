# Search Scope Management

## Overview
Search Scope defines the geographical boundary in the filesystem where the search query will be evaluated.

## Available Scopes
1. **Current Folder**: Only searches within the active open directory (non-recursive).
2. **Current Subtree**: Searches current directory and all subfolders recursively.
3. **Everywhere**: Searches across all mounted drives, partitions, and user libraries.

## How to Toggle
Use the Scope pill button in the Search bar or use keyboard shortcut `Ctrl+Shift+F` to toggle scope.
