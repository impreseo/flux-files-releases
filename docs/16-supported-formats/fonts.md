# Typography & Font Formats

## Overview
Supported font formats:
- **TTF (`.ttf`)**: TrueType fonts.
- **OTF (`.otf`)**: OpenType fonts.
- **WOFF / WOFF2 (`.woff`, `.woff2`)**: Web Open Font Formats.
