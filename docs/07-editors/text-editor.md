# Quick Text Editor

## Overview
The Quick Text Editor offers instant opening and editing for configuration files, notes, and plain text documents.

## Key Controls
- **Save**: `Ctrl+S` commits changes immediately to disk.
- **Save As**: `Ctrl+Shift+S` prompts for a new target filename.
- **Encoding Selector**: Switch between UTF-8, UTF-8 BOM, and ASCII in the editor status bar.
- **Line Endings Selector**: Toggle between CRLF (Windows) and LF (Unix).
