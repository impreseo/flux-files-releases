# Everyday File Management Workflow

## Overview
A step-by-step guide to daily file organization using Flux Files.

## Standard Daily Workflow
1. **Launch & Orient**: Start in **Virtual Home**; review Recent Files or jump to Pinned Folders.
2. **Browse**: Use keyboard arrows or double-click to navigate directories. Use `Alt+Up` to ascend.
3. **Filter**: Type directly into the search bar (`Ctrl+F`) for zero-latency in-folder filtering.
4. **Organize**: Use `F2` to rename, `Ctrl+C` / `Ctrl+V` to copy, `Delete` to trash.
5. **Inspect**: Tap `Space` to preview any document, image, or code file without opening external applications.
