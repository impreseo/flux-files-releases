# Editor Settings

## Overview
Configure built-in editor defaults including font size, tab spacing, line endings, and atomic saving.

## Options Table
| Setting | Default | Description |
|---|---|---|
| **Font Family** | `JetBrains Mono`, `Consolas`, monospace | Editor typography font |
| **Font Size** | 13px | Font size in points |
| **Tab Size** | 2 spaces | Indentation width |
| **Insert Spaces** | On | Replaces Tab key with spaces |
| **Default Line Ending**| CRLF (Windows) | Newline format for newly created files |
| **Atomic Save** | On | Uses temporary staging file for crash-proof saving |
