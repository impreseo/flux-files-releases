# Archive Extraction Errors

## Overview
Resolving compression and extraction errors.

## Common Scenarios
### 1. "Incorrect Password / Encrypted Header"
- **Cause**: Password is missing or typed incorrectly.
- **Solution**: Re-enter password in the Archive Password Prompt.

### 2. "CRC-32 Checksum Mismatch"
- **Cause**: Archive download is corrupted or storage media has bad sectors.
- **Solution**: Run **Test Archive Integrity** to pinpoint damaged files.
