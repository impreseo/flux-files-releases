# 3D & Geometric Formats

## Overview
Supported 3D formats:
- **OBJ (`.obj`)**: Wavefront 3D mesh geometry with material (`.mtl`) support.
- **STL (`.stl`)**: Stereolithography 3D print geometry.
- **GLTF / GLB (`.gltf`, `.glb`)**: Standard 3D transmission format with PBR materials.
