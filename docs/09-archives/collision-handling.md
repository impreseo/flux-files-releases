# Archive Collision Handling

## Overview
When extracting files to a destination containing existing files of the same name, Archive Studio prompts with conflict resolution options:
- **Overwrite**: Replaces destination file with extracted version.
- **Skip**: Retains existing destination file.
- **Keep Both**: Appends a sequential counter to the extracted filename.
- **Apply to All**: Applies selection across all subsequent collisions.
