# Saved Searches & Smart Views

## Overview
Frequently executed search queries can be saved as virtual Smart Searches for immediate re-execution.

## Features
- **Saving a Search**: Click the bookmark icon in the search bar after entering a query and filters.
- **Accessing Saved Searches**: Saved searches appear in the Navigation Sidebar under **Saved Searches**.
- **Dynamic Evaluation**: Clicking a saved search re-evaluates the query in real-time, displaying current matching files on disk.
