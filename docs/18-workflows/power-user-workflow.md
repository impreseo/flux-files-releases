# Power User & Keyboard Mastery Workflow

## Overview
Harnessing maximum efficiency through command palettes and power tools.

## Power User Techniques
1. Press `Ctrl+P` to invoke the **Command Palette**; type any action to execute immediately without touching menus.
2. Use `Ctrl+L` to jump to any Windows path directly.
3. Select multiple files and press **Tools → Batch Rename** to apply complex regex replacements.
4. Use **Tools → Storage Breakdown** to locate large forgotten files in seconds.
