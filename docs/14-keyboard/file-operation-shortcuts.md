# File Operation Shortcuts

## Overview
Shortcuts for manipulating files, folders, and clipboard buffers.

## Reference Table
| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+C` | Copy | Stages selected items to clipboard |
| `Ctrl+X` | Cut | Stages selected items for relocation (translucent) |
| `Ctrl+V` | Paste | Transfers staged clipboard items to active folder |
| `Ctrl+D` | Duplicate | Creates immediate in-place copy with " - Copy" suffix |
| `F2` | Rename | Activates inline text renaming for selected item |
| `Delete` | Delete to Trash | Moves selected items safely to Windows Recycle Bin |
| `Shift+Delete` | Permanent Delete | Irrevocably purges item bypassing Recycle Bin |
| `Ctrl+A` | Select All | Highlights all items in the active view |
| `Escape` | Clear Selection | Deselects all highlighted items |
| `Ctrl+Shift+N` | New Folder | Opens dialog to create a new directory |
| `Ctrl+Alt+N` | New File | Opens dialog to create a blank document |
| `Alt+Enter` | Properties | Opens detailed file attributes modal |
