# JSON Editor

## Overview
The JSON Editor combines text editing with live schema and syntax validation.

## Features
- **Real-Time Linting**: Flags syntax errors (trailing commas, unclosed quotes) with inline line badges.
- **Auto-Format / Prettify**: Press `Ctrl+Shift+I` to format and indent JSON cleanly.
- **Minify**: Compact JSON into a single line for production payloads.
