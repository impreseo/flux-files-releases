# Pasting Files & Folders

## Overview
Pasting executes the queued transfer of clipboard-staged items into the active destination directory.

## Controls & Accelerators
- Press `Ctrl+V` or choose **Edit → Paste**.
- **Paste Shortcut**: Creates `.lnk` Windows shortcut files pointing back to the original source location.

## Handling Same-Directory Pastes
If items are copied and pasted within the identical directory, Flux Files automatically duplicates them with an incremented suffix (e.g. `document - Copy.txt` or `document - Copy (2).txt`).
