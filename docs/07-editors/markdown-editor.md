# Markdown Live Editor

## Overview
The Markdown Editor provides a split-view editing experience with raw Markdown on the left and real-time rendered preview on the right.

## Visual Interface
![Markdown Live Editor](./screenshots/editor-markdown-live.png)
*Figure 07.2: Markdown Live Editor with dual-pane synchronous scrolling.*

## Features
- **Synchronized Scrolling**: Scrolling the source editor scrolls the rendered preview proportionally.
- **Formatting Toolbar**: One-click bold, italic, headings, lists, tables, and link insertion.
- **Table Editor**: Visual grid for easily editing Markdown tables.
