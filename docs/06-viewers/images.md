# Image Viewer

## Overview
The Image Viewer displays raster, vector, and raw photography formats with high-fidelity rendering, pan-and-zoom inspection, and EXIF metadata extraction.

## Visual Interface
![Image Viewer Pan Zoom](./screenshots/viewer-image.png)
*Figure 06.6: Image Viewer with smooth zoom magnification and dimension statistics.*

## Supported Formats
PNG, JPG/JPEG, WEBP, GIF, SVG, BMP, ICO, TIFF, and RAW camera formats (CR2, NEF, ARW).

## Controls
- **Mouse Wheel**: Smooth zoom centered at cursor position.
- **Drag**: Pan across magnified images.
- **`Ctrl+0`**: Reset zoom to fit screen.
- **`Ctrl+1`**: Actual pixels (100% scale).
- **Rotate**: Rotate 90° clockwise/counter-clockwise.
