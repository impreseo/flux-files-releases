# Recycle Bin Management

## Overview
Flux Files integrates directly with the native Windows Recycle Bin shell API.

## Features
- Accessible via Sidebar or by navigating to `flux://recycle-bin`.
- Displays deleted items with original location paths and deletion timestamps.
- **Empty Recycle Bin**: One-click purge to reclaim all deleted storage capacity.
