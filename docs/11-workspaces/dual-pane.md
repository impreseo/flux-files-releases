# Dual-Pane Architecture

## Overview
Dual-Pane mode displays two independent, full-featured explorer panes side by side within a single window.

## Visual Interface
![Dual Pane Split](./screenshots/dual-pane-split.png)
*Figure 11.3: Dual-pane layout enabling rapid cross-directory copying and comparisons.*

## Features & Workflows
- **Independent Navigation**: Each pane maintains its own path, view mode, sort order, and selection state.
- **Active Pane Indicator**: A focused blue border clearly identifies which pane receives keyboard input.
- **Fast Cross-Pane Transfer**: Press `F5` to copy selected items from the active pane directly to the inactive pane's directory. Press `F6` to move.
- **Toggle**: Toggle Dual Pane via **View Menu → Dual Pane** or shortcut `Ctrl+Shift+2` (pane mode).
