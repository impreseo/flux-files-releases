# PDF Viewer

## Overview
Flux Files includes a native PDF rendering engine for viewing documents without launching external readers.

## Visual Interface
![PDF Viewer](./screenshots/viewer-pdf.png)
*Figure 06.9: Multi-page PDF viewer with thumbnail sidebar and text search.*

## Features
- **Page Navigation**: Jump to page, next/previous buttons, and thumbnail sidebar.
- **Zoom Modes**: Fit to Width, Fit to Page, and custom percentage zoom.
- **Text Selection & Search**: Highlight and copy text, or search using `Ctrl+F`.
