# Keyboard Settings & Custom Shortcuts

## Overview
Customize and rebind any keyboard shortcut in Flux Files.

## Features
- **Filterable Shortcut List**: Search actions by command name or current hotkey.
- **Conflict Detection**: Warns if a newly assigned key combination clashes with an existing shortcut.
- **Reset to Defaults**: Restore original factory keybindings with a single click.
