# Video Formats

## Overview
Supported video containers:
- **MP4 (`.mp4`, `.m4v`)**: H.264 / AAC hardware-accelerated playback.
- **WebM (`.webm`)**: VP8/VP9 / Opus open web video playback.
- **MKV (`.mkv`)**: Matroska multimedia container playback.
