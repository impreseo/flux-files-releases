# Windows Shell & Context Menu Integration

## Overview
Users can integrate Flux Files into the standard Windows Explorer right-click context menu.

## Available Shell Hooks
- **"Open in Flux Files"**: Adds context menu option when right-clicking any folder in Windows Explorer.
- **"Open Terminal Here"**: Spawns Windows Terminal or PowerShell at the selected directory.
