# Font Specimen Viewer

## Overview
The Font Specimen Viewer renders TrueType (`.ttf`), OpenType (`.otf`), and Web Open Font Format (`.woff`, `.woff2`) files with interactive typography previews.

## Visual Interface
![Font Specimen Viewer](./screenshots/viewer-font-specimen.png)
*Figure 06.11: Font Specimen Viewer showing glyph preview, waterfall point sizing, and metadata.*

## Features
- **Interactive Waterfall**: View font rendered across multiple point sizes (12pt, 18pt, 24pt, 36pt, 48pt, 72pt).
- **Custom Preview Text**: Type custom strings to test specific character pairings and kerning.
- **Glyph Table**: Complete Unicode glyph catalog inspection.
- **Font Metadata**: PostScript name, family, designer, copyright, and version.
