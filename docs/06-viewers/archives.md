# Archive Inspector

## Overview
The Archive Inspector allows users to browse the directory tree and file contents of compressed archives virtually without extracting them to disk.

## Visual Interface
![Archive Contents Browser](../09-archives/screenshots/archive-virtual-browser.png)
*Figure 06.10: Virtual archive browser inspecting ZIP compressed package hierarchy.*

## Features
- **Virtual Directory Traversal**: Browse folders inside archives as if they were local directories.
- **Selective Extraction**: Extract individual files or folders without uncompressing the entire archive.
- **Compression Metadata**: View compression method, uncompressed size, compressed size, and CRC-32 checksum.
