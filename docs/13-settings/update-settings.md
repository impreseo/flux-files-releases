# Update Settings

## Overview
Configure software update checking and release channels.

## Visual Interface
![Settings Updates](./screenshots/settings-updates.png)
*Figure 13.7: Software update configuration options.*

## Options
- **Automatically Check for Updates**: Enable or disable background checking.
- **Update Channel**: **Stable** (production releases) or **Beta** (pre-release testing).
- **Check Now**: Immediately queries the update manifest for newer versions.
