# Go Menu

## Overview
The **Go** menu offers rapid directional jumps across the directory tree, virtual hubs, and Windows system locations.

## Menu Items Table
| Item | Shortcut | Target Destination |
|---|---|---|
| **Back** | `Alt+Left` | Preceding folder in tab history |
| **Forward** | `Alt+Right` | Next folder in tab history |
| **Enclosing Folder (Up)**| `Alt+Up` / `Backspace` | Parent directory on disk |
| **Home** | `Alt+Home` | Virtual Home dashboard |
| **This PC** | — | Root storage drives view |
| **Desktop** | — | User Desktop folder |
| **Downloads** | — | User Downloads folder |
| **Documents** | — | User Documents folder |
| **Pictures** | — | User Pictures folder |
| **Music** | — | User Music folder |
| **Videos** | — | User Videos folder |
| **Recycle Bin** | — | Windows Recycle Bin |
| **Go to Location...** | `Ctrl+L` / `Alt+D` | Focuses Address Bar for direct path input |
