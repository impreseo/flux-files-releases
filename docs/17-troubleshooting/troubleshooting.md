# Troubleshooting & Diagnostic Guide

## Overview
This guide provides verified recovery steps for known operational edge cases, permission denials, locked files, and search diagnostics.

## General Diagnostic Checklist
1. Open **Help → Search Diagnostics** to check database health and memory usage.
2. Check the **Status Bar** and **Operation Center** for error alerts.
3. Review **Settings → Reset** if preferences need to be restored to factory defaults.
