# Developer & Code Management Workflow

## Overview
Navigating repositories, reviewing diffs, inspecting logs, and launching terminals.

## Developer Workflow Steps
1. Navigate to project root; use **List View** (`Ctrl+Shift+5`) for fast file scanning.
2. Select any source file and tap `Space` to inspect with full syntax highlighting.
3. Press `Ctrl+E` to open the in-app Code Editor for quick edits and save with `Ctrl+S`.
4. Right-click whitespace and select **Open Terminal Here** to launch Windows Terminal.
5. Select two files and choose **Tools → File Compare** to visually diff revisions.
