# Viewer Errors & Unsupported Files

## Overview
Resolving issues where files cannot be previewed in the Universal Viewer.

## Common Scenarios
### 1. "File Exceeds Maximum Preview Budget"
- **Cause**: File exceeds the configured preview size threshold (default 50 MB) to prevent RAM exhaustion.
- **Solution**: Increase preview size limit in **Settings → Viewers**, or click **Open Externally**.

### 2. "Corrupted Media / Missing Codec"
- **Cause**: Media file uses an unsupported proprietary codec.
- **Solution**: Right-click file and choose **Open With...** to launch in an external player like VLC.
