# View Modes Overview

## Overview
Flux Files offers eight specialized view modes tailored for different workflows—from high-density technical analysis to rich visual media curation.

## Supported Modes Summary
| Mode | Accelerator | Best Used For |
|---|---|---|
| **Details** | `Ctrl+Shift+6` | System directories, technical audits, multi-column sorting |
| **List** | `Ctrl+Shift+5` | Rapid skimming of large flat directories |
| **Compact Grid** | `Ctrl+Shift+4` | Dense icon layout maximizing screen real estate |
| **Medium Icons** | `Ctrl+Shift+3` | General file browsing with visible thumbnails |
| **Large Icons** | `Ctrl+Shift+2` | Photo, video, and design asset curation |
| **Extra Large** | `Ctrl+Shift+1` | High-resolution photography review |
| **Gallery** | `Ctrl+Shift+7` | Focused photo inspection with filmstrip carousel |
| **Column** | `Ctrl+Shift+8` | Deep nested hierarchy traversal (Miller Columns) |
