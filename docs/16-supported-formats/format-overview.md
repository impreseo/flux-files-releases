# Supported Formats Overview

## Overview
Flux Files incorporates the **Universal Format Engine**, providing native decoding, thumbnail generation, metadata extraction, and in-app inspection for over 50 formats.

## Categorical Breakdown
- **Documents & Text**: Markdown, PDF, Plain Text, RTF, Office doc inspection.
- **Images & Photography**: PNG, JPG, WEBP, GIF, SVG, BMP, ICO, TIFF, RAW camera files.
- **Media**: MP4, WebM, MKV video; MP3, FLAC, WAV, OGG audio.
- **3D & CAD**: OBJ, STL, GLTF, GLB, CAD wireframes.
- **Developer Assets**: Source code (40+ languages), JSON, CSV, TSV, Fonts (TTF, OTF, WOFF).
- **Databases & Machine Learning**: SQLite, ONNX, Safetensors.
- **Archives**: ZIP, 7Z, TAR, GZ.
