# Windows System & Binary Formats

## Overview
Supported Windows system formats:
- **PE Binaries (`.exe`, `.dll`, `.sys`)**: Header inspection (architecture, compile time, subsystem).
- **Shortcuts (`.lnk`)**: Target path, working directory, and argument decoding.
- **Raw Binary (`.bin`, `.dat`, `.hex`)**: Hexadecimal byte editor.
