# Hash Calculator & Integrity Verifier

## Overview
The Hash Calculator computes cryptographic digests to verify file integrity and detect tampering.

## Supported Hash Algorithms
- **MD5**: 128-bit legacy digest.
- **SHA-1**: 160-bit standard digest.
- **SHA-256**: 256-bit secure cryptographic standard.
- **SHA-512**: 512-bit high-security digest.

## Hash Comparison
Paste an expected checksum from a software vendor into the comparison input. Flux Files compares the computed digest and displays a green match badge or red mismatch warning.
