# Image & Photography Formats

## Overview
Supported image formats:
- **Raster**: PNG, JPG/JPEG, WEBP, GIF (animated), BMP, ICO, TIFF.
- **Vector**: SVG (scalable vector graphics with XML source inspection).
- **RAW Photography**: Canon (`.cr2`), Nikon (`.nef`), Sony (`.arw`), Adobe DNG.
