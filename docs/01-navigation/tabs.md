# Tabs & Multi-Tab Workspaces

## Overview
Flux Files features a browser-grade tab strip that allows users to manage multiple concurrent directory sessions inside a single window, preventing desktop clutter.

## Visual Interface
![Tabs Strip](./screenshots/tabs-strip.png)
*Figure 01.5: Tab strip with multiple active directory tabs and pinned indicators.*

## Features & Capabilities
- **Tab Persistence**: Active tab paths and view settings are preserved during navigation.
- **Pinned Tabs**: Lock essential reference directories to the left of the tab strip with compact icons.
- **Tab Reordering**: Drag and drop tabs horizontally along the strip to reorder.
- **New Tab Creation**: Click the `+` button or press `Ctrl+T` to duplicate current location or launch Virtual Home.
- **Duplicate Tab**: Right-click any tab and select **Duplicate Tab** to branch navigation.
- **Close Options**: Middle-click tab header, click `x` button, or right-click to choose **Close Other Tabs** or **Close Tabs to the Right**.

## Keyboard Shortcuts
| Shortcut | Action |
|---|---|
| `Ctrl+T` | Open New Tab |
| `Ctrl+W` | Close Active Tab |
| `Ctrl+Tab` | Switch to Next Tab |
| `Ctrl+Shift+Tab` | Switch to Previous Tab |
| `Ctrl+1` - `Ctrl+8` | Switch directly to Tab 1 through 8 |
| `Ctrl+9` | Switch to Last Tab |
| `Ctrl+Shift+T` | Reopen Last Closed Tab |
