# Flux Files — Quick Start Guide

Welcome to Flux Files. Follow these quick steps to get started:

## 1. Installation & First Launch
- **Installer**: Run `Flux-Files-1.0.0-Setup.exe` and complete setup.
- **Portable**: Run `Flux-Files-1.0.0-Portable.exe` directly without installation.

## 2. Navigating Drives & Folders
- Use the **Sidebar** to jump to Virtual Home, This PC, your local drives, or user libraries.
- Click any **Breadcrumb** pill in the address bar to jump directly to parent directories.
- Press `Ctrl+L` to type or paste Windows paths directly.

## 3. Essential Keyboard Shortcuts
- `Space` — Universal Quick Preview for documents, code, images, video, audio, and 3D models.
- `Ctrl+F` — Search current folder.
- `Ctrl+Shift+F` — Search Everywhere across all connected drives.
- `Ctrl+T` / `Ctrl+W` — Open new tab / Close active tab.
- `Ctrl+Shift+1` to `Ctrl+Shift+8` — Switch between all 8 Explorer view modes.
- `F2` — Rename selected file or folder.
- `Delete` — Safely move item to Windows Recycle Bin.
- `Ctrl+P` — Open Command Palette.
- `Ctrl+,` — Open Settings.

## 4. Workspaces & Dual Pane
- Open **View → Dual Pane** to browse two folders side-by-side with fast `F5` (copy) and `F6` (move) transfers.
- Drag tabs to rearrange or pin reference tabs to the left.
