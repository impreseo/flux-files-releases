# Duplicating Files & Folders

## Overview
Duplication creates an instantaneous in-place replica of selected files or folders without altering the system clipboard.

## Workflow
1. Select target file(s).
2. Press `Ctrl+D` or select **Edit → Duplicate**.
3. Flux Files immediately creates duplicate items named with ` - Copy` appended.
