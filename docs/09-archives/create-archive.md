# Creating Archives

## Overview
Archive creation packages one or more files and folders into a compressed archive file.

## Workflow
1. Select target file(s) or folder(s) in the Explorer.
2. Right-click and choose **Create Archive...**, or press **Tools → Create Archive**.
3. Select desired format (ZIP, 7Z, TAR).
4. Choose compression level (Fastest to Ultra).
5. (Optional) Enter a password to apply AES-256 encryption.
6. Click **Create Archive**.

## Compression Options
| Option | Levels | Trade-off |
|---|---|---|
| **Store (0)** | 0% compression | Instant speed, zero CPU overhead |
| **Fast (1-3)** | Light compression | Rapid compression for large transfers |
| **Normal (5)** | Balanced | Optimal balance of speed and file size |
| **Ultra (9)** | Maximum compression | Highest byte reduction; uses more CPU |
