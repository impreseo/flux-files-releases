## Screenshot Library Architecture

All visual assets in this documentation library are real, high-resolution captures from the running Flux Files application organized in `images/`:

```
product-assets/handbook/images/
├── overview/             # Main interface, virtual home, startup views
├── navigation/           # Sidebar, breadcrumb address bar, tab strip
├── explorer/             # Details, list, grid, and gallery view modes
├── menus/                # File, Edit, View, Tools, Help menu surfaces
├── file-operations/      # Selection, copy, rename, properties, new items
├── search/               # In-folder filter, Everywhere search, filter syntax
├── viewers/              # Markdown, code, JSON, CSV, PDF, hex, 3D, fonts
├── editors/              # Quick text editor, live Markdown editor, dirty state
├── media/                # Video player, audio waveform player
├── archives/             # Virtual archive browser, extraction, compression
├── workspaces/           # Dual-pane split view, pinned tabs
├── power-tools/          # Batch rename, storage analyzer, duplicate finder
├── settings/             # General, appearance, files, search, updates
├── windows/              # Native properties, Open With, Windows drives
└── troubleshooting/      # Inaccessible path notices, empty search states
```

## Core Product Pillars

1. **FAST**: Sub-millisecond virtual list rendering, asynchronous background file system access, and instant indexed search.
2. **LOCAL**: Pure on-device execution. No cloud accounts, no subscriptions, no external servers.
3. **PRIVATE**: Absolute local confidentiality. Zero telemetry beacons, zero error reporting to third-party endpoints.
4. **SIMPLE**: Clean Fluent UI design with ergonomic keyboard shortcuts and zero bloated clutter.
