# Appearance & Visual Customization

## Overview
Customize color themes, UI density, animations, and typography.

## Visual Interface
![Settings Appearance](./screenshots/settings-appearance.png)
*Figure 13.2: Appearance settings panel with theme presets and UI scale sliders.*

## Options Table
| Setting | Options | Default | Effect |
|---|---|---|---|
| **Theme Preset** | Flux Dark, Flux Light, Slate, Graphite, System Sync | Flux Dark | Changes complete UI color scheme |
| **Density Mode** | Compact, Default, Comfortable | Default | Adjusts row heights, icon paddings, and font sizes |
| **UI Animations**| Enabled / Reduced Motion | Enabled | Controls transition animations across panes |
| **High Contrast**| On / Off | Off | Increases border delineation for accessibility |
