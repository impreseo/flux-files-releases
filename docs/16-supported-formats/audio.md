# Audio Formats

## Overview
Supported audio formats:
- **MP3 (`.mp3`)**: MPEG audio with ID3 metadata tags.
- **FLAC (`.flac`)**: Lossless audio with waveform rendering.
- **WAV (`.wav`)**: Uncompressed PCM audio.
- **OGG (`.ogg`)**: Ogg Vorbis audio.
- **AAC / M4A (`.aac`, `.m4a`)**: Advanced audio coding.
