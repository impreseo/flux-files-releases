# CSV Editor

## Overview
The CSV Editor allows tabular cell editing directly within Flux Files.

## Features
- **Cell-Based Editing**: Double-click any cell to modify its value.
- **Row & Column Controls**: Add, delete, and reorder columns and rows.
- **Safe Quoting**: Automatically quotes strings containing delimiters or newline characters upon save.
