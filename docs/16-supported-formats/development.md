# Developer & Source Code Formats

## Overview
Supported development formats:
- **Languages**: TypeScript (`.ts`, `.tsx`), JavaScript (`.js`, `.jsx`), Python (`.py`), Rust (`.rs`), Go (`.go`), C/C++ (`.c`, `.cpp`, `.h`), C# (`.cs`), Java (`.java`), SQL (`.sql`), HTML/CSS (`.html`, `.css`), Shell/PowerShell (`.sh`, `.ps1`, `.bat`).
- **Configs**: YAML (`.yaml`, `.yml`), TOML (`.toml`), INI (`.ini`), XML (`.xml`).
