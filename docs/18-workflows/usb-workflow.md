# USB Transfer & Backup Workflow

## Overview
Safely transferring files between internal storage and removable media.

## USB Workflow Steps
1. Plug in USB drive; watch it automatically appear under **Drives** in the sidebar.
2. Open Dual-Pane mode (**View → Dual Pane**).
3. Set Left Pane to internal project folder and Right Pane to USB drive.
4. Select files on left and press `F5` to copy across to the USB drive.
5. When complete, right-click the USB drive in the sidebar and choose **Eject Drive**.
