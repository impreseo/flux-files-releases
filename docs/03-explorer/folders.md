# Folders & Directory Navigation

## Overview
Folders are the fundamental structural containers in Flux Files. The application optimizes folder reading with async directory scanning and aggressive metadata caching.

## Folder Features
- **Item Count Indicators**: Subfolder row displays child file/folder counts in details mode.
- **Folder Memory**: Flux Files remembers the chosen view mode, column widths, and sort order independently for each folder.
- **Pinning**: Pin frequently accessed folders to the sidebar for one-click access.
- **Opening in Tabs/Windows**: `Ctrl+Enter` opens highlighted folder in a new background tab; `Ctrl+Shift+Enter` opens in a new window.
