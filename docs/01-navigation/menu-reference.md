# Menu System Reference

## Overview
Flux Files features a standard Windows desktop menu bar providing organized access to every file operation, view transformation, workspace utility, and application diagnostic.

## Menu Bar Layout
The top-level menu bar contains six core categories:
1. **File**: Window, tab, folder/file creation, properties, and exit.
2. **Edit**: Clipboard, selection, renaming, duplication, and undo/redo.
3. **View**: 8 view modes, sorting, grouping, pane toggles, and zoom.
4. **Go**: History navigation, parent folder, virtual hubs, and direct drive paths.
5. **Tools**: Batch renamer, duplicate finder, storage analyzer, hash calculator, file compare, and settings.
6. **Help**: Shortcuts, command palette, diagnostics, documentation, update check, and about dialog.
