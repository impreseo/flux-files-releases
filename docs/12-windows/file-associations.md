# File Associations & Protocol Handlers

## Overview
Flux Files registers the custom URI protocol `flux://` to support deep-linking:
- `flux://home` — Opens Virtual Home
- `flux://this-pc` — Opens storage drives
- `flux://recycle-bin` — Opens Recycle Bin
