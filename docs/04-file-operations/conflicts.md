# Collision & Conflict Resolution

## Overview
When copying or moving files into a destination where matching filenames already exist, Flux Files triggers the Conflict Resolution dialog.

## Resolution Strategies
- **Overwrite / Replace**: Replaces target file with the incoming source file.
- **Skip**: Leaves existing destination file intact and skips the transfer.
- **Keep Both**: Renames incoming file automatically (e.g. `report (1).pdf`).
- **Apply to All**: Applies the chosen resolution strategy across all subsequent collisions in the current transfer batch.
