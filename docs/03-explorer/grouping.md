# Grouping Files & Folders

## Overview
Grouping divides directory contents into expandable and collapsible semantic clusters, making large folders easy to parse.

## Visual Interface
![Grouped View](./screenshots/grouped-view.png)
*Figure 03.4: Directory grouped by Format Category into Documents, Images, and Code.*

## Grouping Criteria
- **None**: Default flat list.
- **Type**: Bucketed into Documents, Images, Video, Audio, Archives, Code, System, and Other.
- **Date Modified**: Bucketed into Today, Yesterday, Earlier this week, Earlier this month, Older.
- **Size**: Bucketed into Tiny (0-10 KB), Small (10-100 KB), Medium (100 KB-1 MB), Large (1-16 MB), Huge (16-128 MB), Gigantic (>128 MB).
- **Alphabetical**: Bucketed by starting letter (`A-D`, `E-H`, etc.).

## Controls
- Click the chevron next to any group header to collapse or expand that specific section.
- Right-click group header to **Collapse All Groups** or **Expand All Groups**.
