# Explorer & Navigation Settings

## Overview
Configure core filesystem browsing behavior.

![Settings Files](./screenshots/settings-files.png)
*Figure 13.5: Files and Explorer configuration options.*

## Options Table
| Setting | Options | Default | Effect |
|---|---|---|---|
| **Show Hidden Files** | On / Off | Off | Displays Windows hidden files and folders |
| **Show System Protected Files** | On / Off | Off | Displays OS-protected files (`desktop.ini`, etc.) |
| **Show File Extensions** | On / Off | On | Displays extensions like `.txt`, `.png` in names |
| **Open Item Action** | Double-Click / Single-Click | Double-Click | Determines mouse gesture to open items |
| **Default View Mode** | Details, List, Icons, etc. | Details | View mode applied to unconfigured folders |
| **Remember Folder Views** | On / Off | On | Persists per-directory layout preferences |
