# Plain Text Viewer

## Overview
The Plain Text Viewer provides fast, zero-delay inspection of unstructured text documents with automatic encoding detection and line-wrapping controls.

## Capabilities
- **Encoding Support**: UTF-8, UTF-16 LE/BE, ASCII, Windows-1252.
- **Large File Optimization**: Streams files larger than 10 MB in chunks to prevent memory bloat.
- **Controls**: Toggle Line Wrapping, Copy All, In-text Search (`Ctrl+F`), and Open in Editor.
