# Archive Encryption & Security

## Overview
Archive Studio provides AES-256 encryption to protect sensitive data inside archives.

## Security Features
- **AES-256 Symmetric Encryption**: Industry-standard cryptographic protection.
- **7Z Header Encryption**: In 7Z format, encrypts filenames and directory structure so unauthorized users cannot even view the file list without the password.
- **Memory Wipe**: Encryption keys and passwords are wiped from RAM after archive creation or extraction.
