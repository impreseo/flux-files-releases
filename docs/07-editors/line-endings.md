# Line Endings (CRLF & LF)

## Overview
Flux Files supports cross-platform newline conversions:
- **CRLF (`\r\n`)**: Standard Windows line breaks.
- **LF (`\n`)**: Standard Linux/macOS line breaks.

The active line ending is displayed in the bottom-right status bar of the editor and can be toggled with a single click.
