# Code Editor

## Overview
The Code Editor provides code editing with syntax highlighting, auto-indentation, and bracket matching.

## Supported Languages
TypeScript, JavaScript, JSON, HTML, CSS, Python, Rust, Go, C++, SQL, Bash, Batch, PowerShell.

## Features
- **Auto-Indentation**: Preserves indent levels and converts tabs to spaces according to preferences.
- **Shortcut Support**: Standard editor accelerators including `Ctrl+/` (toggle line comment), `Ctrl+D` (duplicate line), `Alt+Up/Down` (move line).
