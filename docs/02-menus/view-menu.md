# View Menu

## Overview
The **View** menu configures layout modes, display density, sorting criteria, grouping axes, pane visibility, and UI scaling.

## Menu Items & Submenus
### 1. View Modes Submenu
| View Mode | Shortcut | Layout Characteristics |
|---|---|---|
| **Details** | `Ctrl+Shift+6` | High-density tabular rows with sortable columns (Name, Date, Type, Size). |
| **List** | `Ctrl+Shift+5` | Multi-column compact vertical list. |
| **Compact Grid** | `Ctrl+Shift+4` | Small icons optimized for maximizing visible count. |
| **Medium Icons**| `Ctrl+Shift+3` | Balanced 48px icons with filename labels below. |
| **Large Icons** | `Ctrl+Shift+2` | 96px icons with thumbnail previews for media and graphics. |
| **Extra Large** | `Ctrl+Shift+1` | 256px ultra-high-resolution thumbnail showcase. |
| **Gallery** | `Ctrl+Shift+7` | Large horizontal preview carousel with scrolling thumbnail filmstrip. |
| **Column** | `Ctrl+Shift+8` | Miller-columns cascading multi-tier directory browser. |

### 2. Sort By Submenu
- **Name**: Alphabetical order.
- **Date Modified**: Chronological order of last modification.
- **Type / Extension**: Categorized by format extension.
- **Size**: Sorted by byte count.
- **Ascending / Descending**: Toggle direction order.

### 3. Group By Submenu
- **None**: Flat continuous list.
- **Type**: Bucketed into Documents, Media, Archives, Code, etc.
- **Date Modified**: Grouped by Today, Yesterday, This Week, Earlier this Year.
- **Size**: Grouped into Tiny, Small, Medium, Large, Gigantic.

### 4. Panes Submenu
- **Navigation Pane (Sidebar)**: Toggle sidebar visibility.
- **Preview Pane** (`Ctrl+Shift+P`): Toggle live right-hand preview panel.
- **Details Pane** (`Ctrl+Shift+D`): Toggle technical file metadata panel.
- **Dual Pane**: Toggle side-by-side dual explorer view.

### 5. Zoom & Density
- **Zoom In** (`Ctrl+=`), **Zoom Out** (`Ctrl+-`), **Reset Zoom** (`Ctrl+0`).
- **Density**: Switch between Compact, Default, and Comfortable row heights.
