# Viewer & Preview Settings

## Overview
Configure in-app inspection limits, auto-preview triggers, and rendering options.

## Visual Interface
![Settings Viewers](./screenshots/settings-viewers.png)
*Figure 13.6: Viewer preferences panel.*

## Options Table
| Setting | Options | Default | Effect |
|---|---|---|---|
| **Enable In-App Previews** | On / Off | On | Toggles native inspection vs external app launch |
| **Auto-Preview on Selection** | On / Off | Off | Automatically renders highlighted file in Preview pane |
| **Max Preview Size** | 10 MB to 200 MB | 50 MB | Caps memory buffer allocated to preview decoders |
| **Syntax Highlighting** | On / Off | On | Colorizes code files in preview and editor |
