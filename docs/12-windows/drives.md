# Windows Drives & Filesystem Support

## Overview
Flux Files supports standard Windows filesystems including **NTFS**, **exFAT**, **FAT32**, and **ReFS**.

## Features
- Real-time free space calculation.
- NTFS alternate data stream awareness.
- Drive label and volume serial number inspection.
