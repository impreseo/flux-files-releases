# 3D Model & CAD Viewer

## Overview
The 3D Model Viewer renders 3D geometric meshes with real-time WebGL hardware acceleration.

## Supported Formats
Wavefront OBJ (`.obj`), Stereolithography (`.stl`), GL Transmission Format (`.gltf`, `.glb`), and CAD wireframes.

## Interactive Controls
- **Left Click + Drag**: Orbit / Rotate model in 3D space.
- **Right Click + Drag**: Pan camera translation.
- **Scroll Wheel**: Smooth camera dolly / zoom.
- **Display Modes**: Shaded, Wireframe, Normal Map, and Bounding Box.
