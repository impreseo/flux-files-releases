# Advanced Search Workflow

## Overview
Efficient techniques for finding files across multi-terabyte storage volumes.

## Recommended Workflow
1. Press `Ctrl+Shift+F` to activate Everywhere Search.
2. Add syntax filters: e.g., `invoice ext:pdf size:>500KB`.
3. Switch View Mode to **Group By → Date Modified** to categorize results chronologically.
4. Right-click matching result and select **Open Containing Folder** to navigate immediately to its location.
