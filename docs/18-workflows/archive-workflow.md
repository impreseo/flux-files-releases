# Archive & Backup Workflow

## Overview
Compressing, encrypting, and transferring backups.

## Workflow Steps
1. Select files or folders to back up.
2. Choose **Tools → Create Archive...**.
3. Select **7Z** format, **Ultra** compression, and enter an AES-256 password.
4. Check **Encrypt File List** to conceal internal filenames.
5. Click **Create Archive**. Verify creation via the Operation Center.
