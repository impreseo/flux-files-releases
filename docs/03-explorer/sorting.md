# Sorting Files & Folders

## Overview
Items in any directory can be dynamically ordered by any metadata attribute in ascending or descending direction.

## Available Sort Criteria
- **Name**: Alphabetical sorting with natural numeric ordering (`File 2` precedes `File 10`).
- **Date Modified**: Order of last write timestamp.
- **Type**: Extension and format category.
- **Size**: File byte size (folders can be calculated or listed at top).
- **Date Created**: Original creation timestamp.

## How to Use
- **In Details View**: Click any column header (Name, Modified, Type, Size). Click again to toggle between Ascending (`↑`) and Descending (`↓`).
- **In Any View**: Select **View Menu → Sort By**, or right-click background whitespace and pick **Sort By**.
