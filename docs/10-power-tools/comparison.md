# File Comparison & Visual Diff

## Overview
File Comparison provides side-by-side visual diffing between two selected text or code files.

## Features
- Highlights added, removed, and modified lines with color-coded gutters.
- Synchronous split scrolling.
- Inline intra-line character difference highlighting.
