# Virtual Archive Inspection

## Overview
Double-clicking any supported archive file in Flux Files opens it in the **Virtual Archive Browser**, allowing seamless inspection of files without extracting to disk.

## Visual Interface
![Archive Virtual Browser](./screenshots/archive-virtual-browser.png)
*Figure 09.2: Virtual archive browser displaying internal files and uncompressed byte sizes.*

## Features
- **File Preview**: Select files inside the archive to preview text, images, or documents.
- **Selective Extraction**: Drag individual files out of the archive into another folder.
