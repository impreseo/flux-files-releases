# Settings System Overview

## Overview
The Settings Modal (`Ctrl+,`) provides granular control over all aspects of Flux Files—from visual aesthetics and explorer layouts to search crawler budgets and keyboard shortcuts.

## Visual Interface
![Settings General](./screenshots/settings-general.png)
*Figure 13.1: Settings modal displaying organized preference tabs and configuration toggles.*

## Available Settings Categories
- **General**: Startup location, language, window restoration, confirmation dialogs.
- **Appearance**: Themes, layout density, font sizes, animations, contrast.
- **Files & Folders**: Hidden items, file extensions, conflict defaults, deletion confirmation.
- **Explorer**: Default view mode, double-click behavior, hover preview, folder memory.
- **Viewers & Previews**: Built-in viewer toggles, auto-preview, memory limits.
- **Search**: Search provider, safe index limits (50k items / 25 MB cap), index rebuild.
- **Keyboard**: Full shortcut remapping, conflict resolution, reset to defaults.
- **Updates**: Update checking channel (Stable/Beta), auto-check preferences.
- **Reset**: Granular reset per category or full factory restore.
