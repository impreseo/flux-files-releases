# Archive Formats

## Overview
Supported compressed archive containers:
- **ZIP (`.zip`)**: Standard Deflate compression and AES-256 encryption.
- **7Z (`.7z`)**: High-compression LZMA2 with header encryption.
- **TAR (`.tar`)**: Unix tape archive container.
- **GZ / TGZ (`.gz`, `.tar.gz`)**: Gzip compressed archives.
