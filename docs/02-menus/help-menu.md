# Help Menu

## Overview
The **Help** menu contains documentation links, shortcut references, real-time diagnostic consoles, update checkers, and software credits.

## Menu Items Table
| Item | Shortcut | Action & Target |
|---|---|---|
| **Keyboard Shortcuts** | `F1` | Opens keyboard shortcuts reference overlay. |
| **Command Palette** | `Ctrl+P` | Opens searchable command palette for all actions. |
| **Documentation** | — | Opens the Flux Files Product Handbook. |
| **Search Diagnostics** | — | Displays database size, index statistics, and crawler health. |
| **Check for Updates** | — | Queries update server for new builds. |
| **About Flux Files** | — | Displays version, build date, license, and system info. |
