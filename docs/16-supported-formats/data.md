# Data & Database Formats

## Overview
Supported data formats:
- **JSON (`.json`)**: Interactive tree rendering and linting.
- **CSV / TSV (`.csv`, `.tsv`)**: Virtualized tabular spreadsheet grid.
- **SQLite (`.sqlite`, `.db`)**: Schema table explorer and SQL query inspector.
