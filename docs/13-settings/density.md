# Density Modes

## Overview
Density modes adjust spatial layout to match screen resolutions and personal ergonomic preferences.

## Available Densities
- **Compact**: 28px row height in Details view; 8px padding. Ideal for viewing thousands of files on dense displays.
- **Default**: 36px row height; 12px padding. Standard desktop ergonomics.
- **Comfortable**: 44px row height; 16px padding. High-contrast readability and touch friendliness.
