# Compression Algorithms & Profiles

## Overview
Flux Files supports multiple compression algorithms tailored for speed or maximum ratio:
- **Deflate**: Standard ZIP compatibility.
- **LZMA / LZMA2**: High-ratio compression used by 7Z archives.
- **Gzip**: Stream compression standard for `.tar.gz` packages.
