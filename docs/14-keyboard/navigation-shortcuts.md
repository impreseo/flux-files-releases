# Navigation Shortcuts

## Overview
Shortcuts for navigating directories, manipulating the address bar, and switching tabs.

## Reference Table
| Shortcut | Action | Scope |
|---|---|---|
| `Alt+Left` / `Browser Back` | Navigate backward in tab history | Active Tab |
| `Alt+Right` / `Browser Forward` | Navigate forward in tab history | Active Tab |
| `Alt+Up` / `Backspace` | Navigate to parent directory | Active Tab |
| `Alt+Home` | Jump to Virtual Home | Active Tab |
| `Ctrl+L` / `Alt+D` | Focus Address Bar for text path entry | Window |
| `Ctrl+T` | Open New Tab | Window |
| `Ctrl+W` | Close Active Tab | Window |
| `Ctrl+Tab` | Switch to Next Tab | Window |
| `Ctrl+Shift+Tab` | Switch to Previous Tab | Window |
| `Ctrl+1` - `Ctrl+8` | Switch directly to Tab 1-8 | Window |
| `Ctrl+9` | Switch to Last Tab | Window |
| `Ctrl+Shift+T` | Reopen Last Closed Tab | Window |
