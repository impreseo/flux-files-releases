# Flux Files — Quick Start Guide
**GET UP AND RUNNING IN 60 SECONDS**

---

## 1. Opening Flux Files
When you launch Flux Files, you land in the **Virtual Home** dashboard. You will see:
- Your pinned folders and quick access hubs.
- Visual storage meters for all your drives.
- Recently opened files.

![Startup Overview](../00-overview/screenshots/startup-overview.png)
*Figure QS.1: Flux Files startup dashboard.*

---

## 2. Navigating Your Files
- **Click Breadcrumbs**: Click any parent folder segment in the address bar to jump up the tree.
- **Type a Path**: Press `Ctrl+L` to type or paste a Windows directory path (e.g. `C:\Projects`).
- **History**: Use `Alt+Left` to go back and `Alt+Up` to go to the parent folder.
- **Tabs**: Press `Ctrl+T` to open a new tab; `Ctrl+W` to close it.

---

## 3. Selecting & Managing Files
- **Select All**: Press `Ctrl+A`.
- **Rename**: Select an item and press `F2`.
- **Copy / Paste**: Press `Ctrl+C` to copy and `Ctrl+V` to paste.
- **Duplicate**: Press `Ctrl+D` to duplicate in-place.
- **Delete**: Press `Delete` to move to Recycle Bin; `Shift+Delete` to permanently delete.

---

## 4. Searching Like a Pro
- **Search Current Folder**: Press `Ctrl+F` and start typing.
- **Search Everywhere**: Press `Ctrl+Shift+F` to search across all your drives.
- **Syntax**: Use `ext:pdf` for PDFs, `type:image` for pictures, or `size:>50MB` for large files.

---

## 5. Instant Preview & Editing
- **Quick Preview**: Select any file and tap `Space`. Inspect text, markdown, images, PDF, code, audio, video, and 3D models natively.
- **Quick Edit**: Press `Ctrl+E` in the viewer to edit text, code, or markdown directly. Save with `Ctrl+S`.

---

## 6. Changing View Modes
Use the toolbar buttons or keyboard shortcuts:
- `Ctrl+Shift+6` — **Details** (Tabular columns)
- `Ctrl+Shift+5` — **List** (Compact multi-column)
- `Ctrl+Shift+2` — **Large Icons** (Thumbnails)
- `Ctrl+Shift+7` — **Gallery** (Media carousel)
- `Ctrl+Shift+8` — **Column** (Miller Columns)

---

## 7. Power Tools
Under the **Tools** menu, you will find:
- **Batch Rename**: Rename hundreds of files with numbering and regex.
- **Duplicate Finder**: Find and delete duplicate files safely.
- **Storage Breakdown**: See what is consuming your disk space.
- **Hash Calculator**: Check SHA-256 and MD5 file integrity.
