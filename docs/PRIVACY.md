# Flux Files — Privacy Philosophy & Guarantees

**FAST. LOCAL. PRIVATE. SIMPLE.**

At QUELRAVO, we believe your files, directory structures, searches, and workflows belong strictly to you.

## 1. Zero Telemetry & Zero Analytics
Flux Files contains:
- Zero diagnostic uploaders.
- Zero analytics pings.
- Zero tracking cookies or advertising identifiers.
- Zero error reporting daemons.

## 2. 100% Local Execution
- All search indexing is executed in an embedded local SQLite database stored on your device.
- All hash calculations, file copies, moves, and compression routines execute directly against native Windows APIs.
- Thumbnails and format previews are decoded strictly on local silicon.

## 3. No Account Required
Flux Files does not require registration, login, email verification, or cloud accounts.

## 4. Air-Gapped Compatibility
Flux Files operates with full functionality on air-gapped systems completely disconnected from the Internet.
