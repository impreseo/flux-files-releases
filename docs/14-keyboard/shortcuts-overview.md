# Keyboard Ergonomics & Shortcuts Overview

## Overview
Flux Files is built with keyboard-first navigation. Almost every visual operation, view change, tab transition, and file manipulation can be executed without leaving the keyboard.

## Key Accelerator Paradigms
- **Global Commands**: Universal triggers (e.g. `Ctrl+P` for Command Palette, `Ctrl+,` for Settings).
- **Navigation Accelerators**: Directional traversal (`Alt+Left`, `Alt+Right`, `Alt+Up`, `Alt+Home`).
- **File Management**: Windows standard clipboard keys (`Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Delete`, `Shift+Delete`, `F2`).
- **View Transforms**: Instant layout mode switching via `Ctrl+Shift+1` through `Ctrl+Shift+8`.
