# Media & Photography Workflow

## Overview
Curating, reviewing, and organizing high-resolution photography and video assets.

## Media Workflow Steps
1. Navigate to photo folder and switch to **Gallery View** (`Ctrl+Shift+7`).
2. Use `Left` / `Right` arrow keys to cycle through images in the filmstrip.
3. Tap `F` to enter borderless fullscreen mode for close inspection.
4. Press `R` to rotate orientation if needed.
5. Press `Ctrl+D` to duplicate or `Delete` to discard rejected photos.
