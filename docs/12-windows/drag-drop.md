# Drag and Drop Subsystem

## Overview
Flux Files supports full OLE drag-and-drop integration with Windows.

## Capabilities
- Drag files from Windows Explorer or desktop directly into Flux Files folders.
- Drag files out of Flux Files into external applications (e.g. Photoshop, VS Code, web browsers).
- Drag tabs to rearrange or tear off into independent windows.
