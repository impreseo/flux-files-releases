# Office Document Inspector

## Overview
Flux Files provides non-destructive structural inspection of Microsoft Office documents (`.docx`, `.xlsx`, `.pptx`) and OpenDocument formats.

## Capabilities
- **Document Structure**: Inspect XML parts, embedded media assets, and text streams.
- **Metadata**: Author, creation dates, revision counts, word counts.
- **Embedded Asset Extraction**: One-click extraction of images and graphics embedded inside Word or PowerPoint presentations.
