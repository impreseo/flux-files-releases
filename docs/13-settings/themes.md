## Palette Specifications
1. **Flux Dark (Default)**: Background `#090B0D`, Accent `#1683C7`, Text `#F1F4F6`.
2. **Flux Light**: Background `#F3F4F6`, Accent `#1683C7`, Text `#181B1F`.
3. **Slate**: Background `#0F172A`, Accent `#3B82F6`, Text `#F8FAFC`.
4. **Graphite**: Background `#141416`, Accent `#64748B`, Text `#F3F4F6`.
5. **System Sync**: Automatically mirrors Windows dark/light OS mode.
