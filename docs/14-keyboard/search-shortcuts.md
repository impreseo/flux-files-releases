# Search Shortcuts

## Overview
Accelerators for invoking search, altering scope, and cycling search results.

## Reference Table
| Shortcut | Action |
|---|---|
| `Ctrl+F` | Focus Search Bar in current folder |
| `Ctrl+Shift+F` | Toggle Everywhere Search scope |
| `Enter` | Commit search query or open highlighted result |
| `Up` / `Down` | Cycle through matching search results |
| `Escape` | Clear active search filter and restore full directory |
