# CSV & Tabular Data Viewer

## Overview
The CSV Viewer parses comma-separated (`.csv`) and tab-separated (`.tsv`) files into an interactive data grid.

## Visual Interface
![CSV Tabular Viewer](./screenshots/viewer-csv.png)
*Figure 06.5: Virtualized tabular grid with sorting headers and search filtering.*

## Features
- **Column Sorting**: Click any header to sort numerically or alphabetically.
- **Column Resizing**: Drag column borders to expand text visibility.
- **Delimiter Auto-Detection**: Automatically detects commas, semicolons, tabs, and pipes.
- **Filter Bar**: Filter rows by entering text in the quick filter input.
