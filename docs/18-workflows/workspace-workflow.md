# Workspace & Multi-Project Workflow

## Overview
Structuring multi-directory research, design, and development environments.

## Workflow Steps
1. Open primary project directory in Tab 1. Right-click tab and choose **Pin Tab**.
2. Press `Ctrl+T` to open Tab 2 and navigate to reference documentation.
3. Press `Ctrl+Shift+P` to open the Docked Preview Pane on the right.
4. Switch seamlessly between contexts using `Ctrl+Tab`.
