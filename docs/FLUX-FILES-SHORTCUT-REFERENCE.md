# Flux Files Keyboard Shortcut Reference
**Master Accelerator & Keybinding Manual**  
*Quelravo Systems • Fast. Local. Private. Simple.*

---

Flux Files is built with a keyboard-first philosophy. Nearly every operation across navigation, layout, editing, and file manipulation can be executed without lifting your hands from the keyboard.

---

## 1. General & Window Management

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+T` | New Tab | Opens a new browsing tab in the active pane |
| `Ctrl+W` | Close Tab | Closes the currently active tab |
| `Ctrl+Shift+T` | Restore Closed Tab | Reopens the most recently closed tab |
| `Ctrl+Tab` | Next Tab | Advances focus to the next open tab |
| `Ctrl+Shift+Tab` | Previous Tab | Cycles focus to the preceding open tab |
| `Ctrl+1` – `Ctrl+8` | Select Tab 1–8 | Direct jump to tabs 1 through 8 |
| `Ctrl+9` | Select Last Tab | Focuses the rightmost open tab |
| `Ctrl+,` | Settings | Opens the application preferences modal |
| `F11` | Fullscreen Toggle | Toggles maximized fullscreen display |
| `Alt+F4` | Exit Application | Gracefully saves workspace state and exits |

---

## 2. Navigation & Breadcrumb Traversal

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+L` / `Alt+D` | Focus Address Bar | Activates direct text entry mode for path typing |
| `Alt+Up` / `Backspace` | Parent Directory | Navigates upward one level in folder hierarchy |
| `Alt+Left` | History Back | Steps backward to previously visited directory |
| `Alt+Right` | History Forward | Steps forward in navigation history stack |
| `Alt+Home` | Virtual Home | Returns directly to Virtual Home dashboard |
| `Ctrl+Shift+E` | This PC | Navigates to physical disk drives listing |
| `Enter` | Open Folder / File | Enters highlighted folder or opens file |
| `F5` / `Ctrl+R` | Refresh View | Forces immediate disk re-enumeration |

---

## 3. Selection & Explorer Operations

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+A` | Select All | Selects all files and folders in active view |
| `Ctrl+Shift+I` | Invert Selection | Reverses the current selection set |
| `Shift+Up` / `Down` | Range Select | Expands selection range contiguously |
| `Ctrl+Space` | Toggle Selection | Toggles selection state of focused item |
| `Esc` | Clear Selection | Deselects all items or dismisses active search |

---

## 4. File Operations & Manipulation

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+C` | Copy | Stages selected items for copying |
| `Ctrl+X` | Cut | Stages selected items for moving |
| `Ctrl+V` | Paste | Pastes clipboard items into active folder |
| `Ctrl+Shift+C` | Copy Full Path | Copies absolute Windows file path(s) to clipboard |
| `Ctrl+D` | Duplicate | Clones selected files in place with auto-numbering |
| `F2` | Rename | Activates in-place filename editing |
| `Delete` | Move to Recycle Bin | Safely removes items to Windows Recycle Bin |
| `Shift+Delete` | Permanent Delete | Permanently removes items from disk (prompts) |
| `Ctrl+Shift+N` | New Folder | Displays dialog to create new directory |
| `Ctrl+Alt+N` | New File | Displays dialog to create blank document |
| `Alt+Enter` | Properties | Opens file/folder properties and metadata modal |

| `Ctrl+Shift+2` | List View | Compact multi-column item list |
| `Ctrl+Shift+3` | Medium Grid View | Standard medium icon thumbnail layout |
| `Ctrl+Shift+4` | Large Grid View | Expanded large icon thumbnail layout |

| `Ctrl+Alt+1` | Single Pane View | Returns to standard single-pane layout |

| `Spacebar` | Toggle Inspector | Collapses or expands the right preview panel |
