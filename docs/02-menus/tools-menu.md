# Tools Menu

## Overview
The **Tools** menu provides access to Flux Files power utilities, shell integrations, and application settings.

## Menu Items Table
| Item | Shortcut | Purpose & Function |
|---|---|---|
| **Hash Calculator** | — | Launches hash utility to compute MD5, SHA-1, SHA-256, and SHA-512 hashes. |
| **Batch Rename** | — | Opens batch renamer with regex matching, prefix/suffix, and number sequencing. |
| **Duplicate Finder** | — | Scans target folder to locate identical byte-for-byte duplicate files. |
| **File Compare** | — | Launches side-by-side visual diff comparator for two selected files. |
| **Storage Breakdown** | — | Visualizes folder disk usage with hierarchical size breakdowns. |
| **Open in Terminal** | — | Launches Windows Terminal in the active directory path. |
| **Open in PowerShell**| — | Launches Windows PowerShell in the active directory path. |
| **Settings** | `Ctrl+,` | Opens the comprehensive Flux Files preferences modal. |
