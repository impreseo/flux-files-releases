# Flux Files Release Changelog

## [1.0.0] - 2026-10-06
### Initial Stable Production Release
- **Explorer & Viewports**: 8 distinct layout modes including Details, List, Compact Grid, Medium/Large Icons, Gallery carousel, and Miller Columns.
- **High-Speed Search**: Instant 0ms in-memory active directory filtering and SQLite-backed multi-drive Everywhere Search with syntax operators.
- **Universal Multi-Format Viewers**: Spacebar preview for over 50 formats (Markdown GFM, Code, JSON tree, CSV tabular grid, PDF, Binary Hex, 3D models, Fonts).
- **Atomic Editors**: Built-in text editor and live synchronized Markdown authoring with split-screen preview and atomic crash-proof saving.
- **Archive Studio**: First-class virtual archive browsing for ZIP, 7Z, TAR, and GZ containers without manual pre-extraction; creation and extraction wizards.
- **Dual-Pane Workspaces**: Multi-tab browsing with pinned tabs and side-by-side split view with cross-pane drag-and-drop.
- **Power Tools Suite**: Multi-pattern Batch Renamer, Storage Analyzer, Duplicate Finder, and Cryptographic Hash calculator.
- **Windows Integration**: NTFS attributes, long path support, Recycle Bin safety, and native Open With dispatch.
- **100% Local-First Privacy**: Operates entirely on-device with zero telemetry, zero remote error reporting, and zero accounts.
