# Flux Files — Master Shortcut Reference

## Quick Access Globals
| Shortcut | Action |
|---|---|
| `Ctrl+P` | Command Palette |
| `F1` | Keyboard Shortcuts Help |
| `Ctrl+,` | Settings |
| `Alt+F4` | Exit Application / Close Window |

---

## Navigation & Workspaces
| Shortcut | Action |
|---|---|
| `Ctrl+T` | New Tab |
| `Ctrl+W` | Close Active Tab |
| `Ctrl+Tab` | Next Tab |
| `Ctrl+Shift+Tab` | Previous Tab |
| `Ctrl+1` to `Ctrl+8` | Switch directly to Tab 1-8 |
| `Ctrl+9` | Switch to Last Tab |
| `Ctrl+Shift+T` | Reopen Last Closed Tab |
| `Ctrl+L` / `Alt+D` | Focus Address Bar for text path entry |
| `Alt+Left` | History Back |
| `Alt+Right` | History Forward |
| `Alt+Up` / `Backspace` | Parent Directory |
| `Alt+Home` | Virtual Home |

---

## File Operations
| Shortcut | Action |
|---|---|
| `Ctrl+C` | Copy |
| `Ctrl+X` | Cut |
| `Ctrl+V` | Paste |
| `Ctrl+D` | Duplicate In-Place |
| `F2` | Inline Rename |
| `Delete` | Delete to Windows Recycle Bin |
| `Shift+Delete` | Permanent Delete |
| `Ctrl+A` | Select All |
| `Escape` | Clear Selection |
| `Ctrl+Shift+N` | New Folder |
| `Ctrl+Alt+N` | New File |
| `Alt+Enter` | Properties |

## View Modes & Panes

|---|---|

| `Ctrl+Shift+5` | List View |

| `Ctrl+Shift+3` | Medium Icons View |
| `Ctrl+Shift+2` | Large Icons View |
| `Ctrl+Shift+1` | Extra Large View |
| `Ctrl+Shift+7` | Gallery View |
| `Ctrl+Shift+8` | Column View (Miller Columns) |
| `Ctrl+Shift+P` | Toggle Docked Preview Pane |
| `Ctrl+Shift+D` | Toggle Docked Details Pane |
| `F5` | Refresh Active Directory |
| `Ctrl+=` / `Ctrl+-` | Zoom In / Out |
| `Ctrl+0` | Reset Zoom |

## Search
| Shortcut | Action |
|---|---|
| `Ctrl+F` | Search Current Folder |
| `Ctrl+Shift+F` | Search Everywhere |
| `Escape` | Clear Search Filter |

## Viewers & Editors
| Shortcut | Action |
|---|---|
