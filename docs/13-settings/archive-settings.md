# Archive Settings

## Overview
Configure default archive compression formats, compression levels, and collision behaviors.

## Options
- **Default Format**: ZIP (Default), 7Z, TAR.
- **Default Compression Level**: Normal (5).
- **Default Collision Action**: Ask User, Overwrite, Skip, Keep Both.
