# Document Formats

## Overview
Supported document formats:
- **Markdown (`.md`, `.markdown`)**: Native viewing and live split-pane editing.
- **PDF (`.pdf`)**: Native viewing, zooming, text search, page thumbnails.
- **Plain Text (`.txt`, `.log`, `.cfg`)**: Native viewing and quick text editing.
- **Rich Text (`.rtf`)**: Text stream extraction.
- **Office (`.docx`, `.xlsx`, `.pptx`)**: Structural inspection and asset extraction.
