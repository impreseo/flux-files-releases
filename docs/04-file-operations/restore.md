# Restoring Deleted Files

## Overview
Files moved to the Recycle Bin can be restored to their original location with a single action.

## How to Restore
1. Navigate to **Recycle Bin** in the sidebar.
2. Select the deleted item(s).
3. Right-click and choose **Restore**, or press the **Restore Selected** toolbar button.
4. The items return to their original directory on disk.
