# Performance & Resource Optimization

## Overview
Maintaining smooth 60 FPS performance and low memory consumption.

## Optimization Recommendations
- **Search Database**: Ensure database size stays under 25 MB by excluding massive build directories (`target/`, `node_modules/`).
- **View Density**: Use Details or Compact Grid mode when browsing directories with more than 50,000 files.
- **Hardware Acceleration**: Verify GPU acceleration is enabled in your graphics driver for smooth 3D and video rendering.
