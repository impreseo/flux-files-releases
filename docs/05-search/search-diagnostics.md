# Search Diagnostics & Health Monitoring

## Overview
The Search Diagnostics tool provides real-time visibility into database health, memory allocation, crawler status, and indexing performance.

## Zero Results Handling
![Zero Search Results](./screenshots/zero-search-results.png)
*Figure 05.6: Empty search state providing clear diagnostics and recovery suggestions.*

## Diagnostic Metrics
- **Indexed File Count**: Total files cataloged in local database.
- **Database Size**: In-memory byte size and disk cache size.
- **Crawler Status**: Idle, Crawling, or Paused (Rate-Limited).
- **Query Latency**: Execution time in milliseconds for the last search query.

## How to Access
Open via **Help → Search Diagnostics** or **Settings → Search**.
