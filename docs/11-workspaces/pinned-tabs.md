# Pinned Tabs

## Overview
Pinned Tabs lock frequently accessed reference folders to the left side of the tab strip.

## Visual Interface
![Pinned Tabs](./screenshots/pinned-tabs.png)
*Figure 11.2: Pinned tabs locked compactly at the start of the tab bar.*

## Characteristics
- Pinned tabs consume minimal horizontal space (icon-only mode).
- Cannot be closed via accidental `Ctrl+W` without explicitly unpinning.
- Persist across application restarts.
