# Editor Shortcuts

## Overview
Accelerators active when editing text, markdown, code, or data files in built-in editors.

## Reference Table
| Shortcut | Action |
|---|---|
| `Ctrl+S` | Save file atomically to disk |
| `Ctrl+Shift+S` | Save As (new filename/path) |
| `Ctrl+Z` | Undo last modification |
| `Ctrl+Y` | Redo last reverted modification |
| `Ctrl+F` | Find in document |
| `Ctrl+H` | Find and replace in document |
| `Ctrl+G` | Jump to Line Number |
| `Ctrl+/` | Toggle line comment (code editor) |
| `Ctrl+Shift+I` | Auto-format / Prettify (JSON/code) |
