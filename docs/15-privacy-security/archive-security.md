# Archive Encryption & Protection

## Overview
Flux Files integrates cryptographic protection for archives.

## Capabilities
- AES-256 password protection for ZIP and 7Z archives.
- Encrypted file lists (7Z header encryption) concealing filenames from unauthorized viewers.
- Zero plaintext credential logging.
