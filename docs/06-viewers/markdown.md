# Markdown Viewer

## Overview
The Markdown Viewer parses CommonMark and GitHub Flavored Markdown (GFM) into styled typography.

## Visual Interface
![Markdown Viewer](./screenshots/viewer-markdown.png)
*Figure 06.3: Markdown Viewer rendering headers, badges, alerts, code blocks, and formatted tables.*

## Features
- **GFM Tables & Task Lists**: Interactive checkboxes and bordered tables.
- **Code Block Highlighting**: Syntax highlighting for over 40 programming languages.
- **Heading Outline Navigation**: Table of contents drawer jumping directly to headers.
- **Switch to Live Editor**: Click the **Edit Document** button or press `Ctrl+E` to transition into live split-view markdown editing.
