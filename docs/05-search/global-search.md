# Global "Everywhere" Search

## Overview
Everywhere Search scans across all connected drives and user libraries to locate files regardless of their directory depth.

## Visual Interface
![Search Everywhere](./screenshots/search-everywhere.png)
*Figure 05.2: Everywhere search results spanning multiple storage partitions.*

## How to Use
1. Focus Search by pressing `Ctrl+F` or clicking the toolbar search bar.
2. Type your search query.
3. Select **Everywhere** scope in the scope pill selector.
4. Results stream dynamically into the view with location paths displayed.
