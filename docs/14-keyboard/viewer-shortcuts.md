# Viewer & Preview Shortcuts

## Overview
Accelerators active when inspecting files in docked preview or modal viewer modes.

## Reference Table
| Shortcut | Action |
|---|---|
| `Space` | Quick Preview / Toggle modal viewer |
| `Ctrl+Shift+P` | Toggle Docked Preview Pane |
| `Ctrl+Shift+D` | Toggle Docked Details Pane |
| `Ctrl+0` | Reset Zoom to Fit Viewport |
| `Ctrl+1` | Display at 100% Native Scale (Actual Pixels) |
| `Ctrl+=` / `+` | Zoom In |
| `Ctrl+-` / `-` | Zoom Out |
| `R` | Rotate Image 90 Degrees Clockwise |
| `F` / `F11` | Toggle Borderless Fullscreen Mode |
| `Escape` | Close In-App Modal Viewer |
