# Removable Media & USB Support

## Overview
Flux Files monitors Windows `WM_DEVICECHANGE` messages to dynamically detect USB flash drives, memory cards, and external hard drives upon physical insertion.

## Capabilities
- Automatic sidebar mounting.
- Safe ejection support to prevent filesystem corruption.
