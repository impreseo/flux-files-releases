# Creating Files & Folders

## Overview
Flux Files provides immediate, inline and dialog-driven creation of new directories, blank documents, and templated files.

## Creation Methods
1. **New Folder**: Press `Ctrl+Shift+N`, choose **File → New Folder**, or right-click whitespace and select **New Folder**.
2. **New File**: Press `Ctrl+Alt+N`, choose **File → New File**, or right-click whitespace and select **New File**.
3. **Validation**: Flux Files validates filenames instantly against Windows filesystem reserved characters (`< > : " / \ | ? *`).
