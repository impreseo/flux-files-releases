# Properties Dialog & File Metadata

## Overview
The Properties dialog presents comprehensive technical metadata, filesystem permissions, security attributes, and storage statistics.

## Visual Interface
![Properties Dialog](./screenshots/properties-dialog.png)
*Figure 04.5: Properties dialog displaying file size, creation/modification dates, attributes, and hash digests.*

## Displayed Information
- **General**: Full path, file type, MIME type, default application association.
- **Size**: Exact byte count and cluster-aligned "Size on Disk".
- **Timestamps**: Created, Modified, and Last Accessed.
- **Attributes**: Read-only, Hidden, Archive, and System flags.
- **Checksums**: On-demand calculation of MD5, SHA-1, SHA-256 digests.

## How to Open
Select item and press `Alt+Enter`, or right-click and choose **Properties**.
