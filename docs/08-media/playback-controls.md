# Playback Controls Reference

## Overview
Standardized playback controls for audio and video media surfaces.

## Controls Table
| Action | Keyboard Shortcut | Mouse Action |
|---|---|---|
| **Play / Pause** | `Space` | Click center play button |
| **Seek Forward 5s** | `Right Arrow` | Click seek bar to right |
| **Seek Backward 5s**| `Left Arrow` | Click seek bar to left |
| **Volume Up** | `Up Arrow` | Scroll wheel over volume icon |
| **Volume Down** | `Down Arrow` | Scroll wheel over volume icon |
| **Mute / Unmute** | `M` | Click speaker icon |
| **Fullscreen** | `F` or `F11` | Double click media viewport |
