# Code & Syntax Viewer

## Overview
The Code Viewer provides read-only inspection of source code files with syntax highlighting, line numbers, and language recognition.

## Visual Interface
![Code Viewer](./screenshots/viewer-code.png)
*Figure 06.15: Code Viewer with syntax coloring and line numbers.*

## Features
- **Language Coverage**: TypeScript, JavaScript, Python, Rust, Go, C/C++, C#, HTML, CSS, SQL, YAML, Shell scripts.
- **Line Numbers & Bookmarks**: Toggle line numbers and jump to specific line numbers (`Ctrl+G`).
- **One-Click Edit**: Press `Ctrl+E` to transition into the built-in code editor.
