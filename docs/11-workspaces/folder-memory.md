# Folder View Memory

## Overview
Flux Files automatically records and restores view preferences on a per-folder basis.

## Remembered Properties
- View Mode (e.g., Details for code, Large Icons for photos).
- Sort criteria and direction.
- Grouping settings.
- Column selection and column widths in Details mode.
