# Privacy Policy & Core Commitments

## Overview
Flux Files is developed by QUELRAVO under a strict tenet: **"FAST. LOCAL. PRIVATE. SIMPLE."**

## Core Privacy Guarantees
1. **Zero External Telemetry**: The application never sends analytics, crash dumps, or usage metrics to external servers.
2. **Zero Cloud Dependencies**: All features—indexing, rendering, sorting, hash computation, compression—execute on local silicon.
3. **No Account Required**: Flux Files requires no login, license key phone-home, or personal identification.
4. **Air-Gapped Compatibility**: Flux Files functions with 100% feature parity on computers completely disconnected from the Internet.
