# Flux Files Releases

## v1.0.0 (Official Stable Release)
- **Initial Stable Production Release** for Windows 10 & 11 (64-bit).
- **8 Explorer View Modes**: Details, List, Compact Grid, Medium Icons, Large Icons, Extra Large Icons, Gallery View, and Miller Columns.
- **Universal In-App Viewer Engine**: Over 50 supported formats including Markdown, PDF, JSON trees, CSV data grids, 3D meshes, typography fonts, audio waveforms, video, and binary hex.
- **Built-In Editors**: Plain text, source code, live split-pane Markdown, JSON, and CSV with atomic temporary file writing.
- **Archive Studio**: Create, inspect virtually, extract, and password-protect ZIP, 7Z, and TAR archives with AES-256 encryption.
- **Incident-Resistant Local Search Engine**: In-folder instant filter, Everywhere multi-drive search, syntax operators, and bounded 50k item / 25MB safety caps.
- **Multi-Tab & Dual-Pane Workspaces**: Tab strip with pinned tabs, tab groups, and side-by-side Dual-Pane browsing.
- **Integrated Power Tools**: Batch Renamer with regex, Duplicate Finder with SHA-256, Storage Breakdown treemaps, and Hash Calculator.
- **Native Windows Shell Integration**: Real-time fixed/USB drive monitoring, Recycle Bin COM integration, safe ejection, extended MAX_PATH support, and OLE drag-and-drop.
- **Curated Desktop Aesthetics**: 5 theme presets (Flux Dark Slate, Flux Light, Slate, Graphite, System Sync) and 3 ergonomic density modes.
