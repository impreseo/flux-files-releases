# Video Player

## Overview
The built-in Video Player renders desktop video files with low CPU utilization using hardware acceleration.

## Visual Interface
![Video Player Interface](./screenshots/media-video-player.png)
*Figure 08.2: Video playback with scrubber bar, volume control, and duration timer.*

## Key Features
- **Scrubbing**: High-precision seek bar with timestamp preview.
- **Keyboard Navigation**: Spacebar toggles playback; Arrow Left/Right jumps `±5 seconds`.
- **Fullscreen Mode**: Press `F` or double-click video canvas to expand to borderless fullscreen.
