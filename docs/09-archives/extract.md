# Extracting Archives

## Overview
Extracting uncompresses archive contents to a chosen destination directory.

## Visual Interface
![Archive Extract Dialog](./screenshots/archive-extract-dialog.png)
*Figure 09.3: Extraction destination modal with conflict resolution options.*

## Extraction Methods
1. **Extract Here**: Unpacks contents directly into the current directory.
2. **Extract to Folder**: Creates a subfolder matching the archive name and uncompresses into it.
3. **Extract To...**: Prompts with destination folder picker dialog.
