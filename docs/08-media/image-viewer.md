# Image Viewer & Photography Inspection

## Overview
The dedicated Media Image Viewer provides professional image inspection with fractional zoom scaling, pan controls, and EXIF metadata extraction.

## Controls & Accelerators
| Control | Shortcut / Input | Action |
|---|---|---|
| **Zoom In / Out** | Scroll Wheel / `+` / `-` | Continuous smooth scaling |
| **Fit to Window** | `Ctrl+0` | Scales image to fit viewport boundaries |
| **Actual Size** | `Ctrl+1` | Displays image at 100% native resolution |
| **Pan** | Click + Drag | Traverses magnified image canvas |
| **Rotate** | `R` | Rotates image 90 degrees clockwise |
| **Fullscreen** | `F` / `F11` | Enters distraction-free full-screen mode |
