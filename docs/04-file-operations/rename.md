# Renaming Files & Folders

## Overview
Renaming can be performed via standard inline in-place editing, dialog prompts, or using the advanced batch renamer power tool.

## Inline Renaming
1. Select a single file or folder.
2. Press `F2` or click the name label.
3. The name converts to an inline text box with the base name highlighted (preserving the extension).
4. Type the new name and press `Enter` to commit, or `Escape` to cancel.

## Batch Renaming
For mass renaming operations across dozens or hundreds of files, select the items and choose **Tools → Batch Rename** or press the Batch Rename context action.
